BUILT-IN OFFLINE ENGINE

Công cụ Vietsub tích hợp sẵn

KHÔNG CẦN API KEY
Dịch máy và nhận dạng chạy bằng mô hình đi kèm backend

Không cần tài khoản dịch thuật, API key hoặc dịch vụ AI bên thứ ba. Backend do bạn quản lý dùng Argos Translate, Whisper và FFmpeg. GitHub Pages chỉ là giao diện tĩnh nên cần URL backend riêng để chạy mô hình.

Chưa kiểm tra backend. Không cần nhập API key.

WHISPER · SPEECH TO TEXT

Tạo phụ đề từ giọng nói

Chọn video ở tab Studio trước. Mô hình Whisper chạy ở backend và trả về các mốc thời gian cùng lời thoại gốc.

FFMPEG · HARD SUBTITLES

Ghép phụ đề vĩnh viễn vào video

Dùng chế độ xuất đã chọn ở Studio (Vietsub, song ngữ hoặc bản gốc). Backend tạo một file MP4 mới; file gốc không bị sửa.

Giới hạn mặc định: 200 MB, tối đa 10 phút/video. Tệp video được tải lên backend của bạn chỉ khi chạy nhận dạng hoặc xuất MP4.

OFFLINE WORKFLOW

Quy trình Vietsub hoàn chỉnh

  1. Chọn videoNạp video cục bộ ở tab Studio để xem trước và giữ file cho tác vụ xử lý.
  2. Tạo phụ đề gốcWhisper nhận dạng giọng nói và tạo timeline SRT nháp.
  3. Dịch sang tiếng ViệtArgos Translate chạy mô hình tích hợp; không dùng API key hoặc gọi nhà cung cấp dịch vụ.
  4. Rà soát và căn thời gianSửa lời thoại, căn toàn bộ timeline, tìm/thay thế và kiểm tra chồng lấn.
  5. Xuất bảnTải SRT/VTT/JSON hoặc ghép phụ đề vĩnh viễn vào MP4 bằng FFmpeg.
Lưu ý triển khai

Lần build Docker đầu tải các mô hình mã nguồn mở vào image. Sau đó inference không cần API dịch bên ngoài nhưng cần RAM/CPU đủ dùng. Gói Render Free có thể thiếu tài nguyên cho Whisper.
